# repair-r87

补齐原厂充电接口和旁路供电，恢复系统清零后的第三方PPS自动认证，
保留原装认证流程、32ms手写笔滤波，并修复模块缓存split BTF。

下载包含boot.img、Image、完整项目源码包、Git克隆所需固定源码缓存、
历史提交离线bundle、功能说明与SHA256SUMS。
仓库保持私有，新提交使用peiyuesheng666账号，旧开发历史另存port-history分支。
