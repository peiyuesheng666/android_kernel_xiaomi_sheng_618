# 无线调试开机恢复候选

本机无 root 的实验助手。需要已经能使用 ADB，一次性安装 APK 并授予
`android.permission.WRITE_SECURE_SETTINGS`，打开应用启用；源码构建入口为
`scripts/build_sheng_adb_boot.py`。APK 与开发签名私钥仅保留本地，不入 Git。

开机广播调度持久任务，检测 Wi-Fi 后请求框架启用无线调试。每次开机最多
尝试八次；设置保持启用后，本次开机不再反复开启。应用的关闭按钮取消后续
任务，不会立即关闭当前系统无线调试。框架继续管理可信网络和配对授权。

2026-11-09 实测：安装、授权和重启前设置写入通过；用户手动重启后的三分钟
窗口未恢复可用 ADB。澎湃自启动限制及主机端口发现均可能影响结果，当前
不能认为开机恢复已验证。主机 `discover_sheng_wireless_adb.ps1` 也是未验证的
发现候选，此主机曾在连接正常时返回空列表。不要使用旧端口 offline 作为成功依据。
