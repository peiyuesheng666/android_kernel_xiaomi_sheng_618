# r20 hardware identity correction

The user requires `ro.product.model=24018RPACC` and
`ro.product.marketname=Xiaomi Pad 6S Pro 12.4`. The previous global marketing
model override was wrong; the user reports lost tablet recognition in some
applications. Partition model values and tablet characteristics were already
correct. Application recovery still needs user confirmation after reboot.

The device-owned system.prop now emits the two explicit properties. The
property target compiled successfully in 1 minute 32 seconds. Fresh prebuild
and postbuild fetch audits pass for 14 public repositories; all 1,243
repo-managed projects have clean status. Audit receipts are adjacent JSONs.

The r20 packaging profile uses the exact installed r13 system image and r19
vbmeta_system parent. It changes only these two lines in /system/build.prop,
preserves allocated blocks and inode metadata except file size, checks the
filesystem, and regenerates the system AVB descriptor. Other parent descriptors
must remain byte-identical. Publication uses the existing atomic helper.

The flash helper verifies images by default. Explicit -Revision 20 -Flash
checks all six installed baselines and writes only system_b and
vbmeta_system_b. Native stdout/stderr handling uses the existing process
wrapper. No wipe or slot switch is involved. r19 battery-health and AON
integration remain installed; the user accepted battery SOH 93% and normal
picture/touch, but screen attention still times out and is not accepted.

Packaging and reboot/runtime evidence will be recorded separately. No camera
capture or agent-triggered attention test is part of this correction.
