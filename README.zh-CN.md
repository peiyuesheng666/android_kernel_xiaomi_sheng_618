# 小米平板 6S Pro 最新内核源码

Linux 6.18.32，适配小米平板 6S Pro（sheng，骁龙 8 Gen 2）及 HyperOS OS4.0.2.0.XPYCNXM。

[English](README.md) · [下载最新源码](https://github.com/peiyuesheng666/android_kernel_xiaomi_sheng_618/releases/latest) · [构建步骤](docs/BUILD.zh-CN.md)

- Qualcomm WALT 调度和 CPU 调速。
- 手写笔修复和原厂充电状态接口。
- 必要的温控和充电接口。
- CPU 深度空闲兼容修复。

下载 sheng-kernel-source.tar.gz，包含当前项目、完整固定源码输入和 Git 历史。
包内 git-history.bundle 可用 git clone -b main git-history.bundle restored-kernel 恢复仓库。
